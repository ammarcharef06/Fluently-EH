# تطبيق المتعلم Web/PWA

يستخدم Vite وReact وTypeScript. Service Worker يخزن هيكل التطبيق والملفات الثابتة فقط؛ لا يخزن إجابات أو استجابات API شخصية ولا حزمة المنهج كاملة. حزمة المنهج المنزّلة عند أول استخدام منفصلة عن ملفات PWA.

وضع المعاينة المحلي يعمل في بيئة التطوير فقط. لا يعد تسجيل دخول حقيقيًا، ولا يسمح بالنشر أو المزامنة. في الإنتاج، تبقى الشاشة عند حاجز المصادقة حتى تهيئة مزود موثوق يدعم شروط المجانية والتحقق من الحساب.
