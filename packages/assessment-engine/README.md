# @fluently/assessment-engine

محرك تقييم نصي مستقل عن الواجهة والخادم، يفصل تصحيح الإجابات والتغذية الراجعة والأدلة والإتقان عن `packages/domain`.

## النطاق الحالي
- تصحيح أسئلة الاختيار من متعدد والإجابة النصية القصيرة.
- تغذية راجعة مبنية على نصوص السؤال المعتمدة، مع مثال علاجي ومعرف هدف اختياري.
- إظهار التلميحات بالتتابع دون كشفها دفعة واحدة.
- حساب إتقان الهدف مع احتساب السؤال المميز مرة واحدة مهما تكررت محاولاته.
- تحديد المستوى بناءً على مخطط معاير وموافقة صريحة وحدود وحد أدنى للأدلة ضمن إعدادات المعايرة.
- التحقق من شروط فتح المرحلة وبناء خطة علاجية.

## سياسة الإعدادات
لا توفر الحزمة حدود إتقان أو حدًا أدنى افتراضيًا للأدلة. يجب أن يحدد مخطط التقييم `MasteryRule`، وأن تتضمن المعايرة حد الدرجة و`minimumResponsesBySkill` لكل مهارة مقاسة. الإعداد الناقص أو غير المعتمد لا ينتج تحديد مستوى.

`ASSESSMENT_SKILLS` تستبعد `speaking-practice`. لا توجد واجهات أو أنواع لتسجيل صوت المتعلم أو تحليله أو تقييمه. لا يعتمد المحرك على أي رموز نطق.

## التوافق
`@fluently/domain` يعيد تصدير واجهات التقييم القديمة والجديدة للحفاظ على مستهلكيه الحاليين. تبقى جدولة المراجعة والمزامنة ضمن domain إلى حين إنشاء محركاتها في مراحل مستقلة.

## ملاحظة
قيم الحدود المستخدمة في اختبارات الوحدة بيانات اختبار اصطناعية فقط، وليست معايرة أو سياسة إنتاج معتمدة.
