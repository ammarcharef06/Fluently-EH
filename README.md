# Fluently

**Fluently** منصة مجانية لتعليم اللغة الإنجليزية للناطقين بالعربية، تبدأ من محو الأمية الإنجليزية وتبني مسارًا تدريجيًا حتى مستوى **C2** وفق الإطار الأوروبي المرجعي العام للغات (CEFR).

> **حالة المشروع: تنفيذ تكاملي قيد الإنشاء في `implementation/full-build`.**  
> توجد الآن بنية أولية لتطبيق المتعلم والـAPI ومحرك التعلم والتخزين المحلي ولوحة إدارة منفصلة، لكنها ليست جاهزة للإطلاق. نتيجة H2a التاريخية لا تزال جزئية، والمصادقة والمزامنة الإنتاجية ومخزن الحزم ومراجعة المحتوى البشري والاختبارات على الأجهزة الحقيقية ما زالت تتطلب اعتمادًا أو دليلًا مستقلًا.

## الرؤية

تمكين المتعلم العربي، مهما كان عمره أو مستواه الابتدائي، من اكتساب الإنجليزية الأمريكية تدريجيًا من الصفر، عبر منهج منظم ومراجع، وتجربة تعلم يمكن استخدامها دون اتصال بعد إكمال تسجيل الدخول الأول وتوفر حزمة المنهج محليًا (تنزيل أولي للويب، أو تضمينها في تثبيت Android وWindows).

## مبادئ المشروع

- مجاني للمتعلمين، دون إعلانات أو اشتراكات أو ميزات مدفوعة.
- عدم الاعتماد على فترات تجريبية لخدمات مدفوعة أو خدمات تتطلب التحول إلى اشتراك.
- شرح عربي فصيح مبسط، وتطبيق تدريجي باللغة الإنجليزية.
- منهج يبدأ من الحروف والأصوات والقراءة والكتابة، ثم يطور جميع المهارات.
- اعتماد مستويات CEFR من Pre-A1 إلى C2، مع تقسيم داخلي مفصل.
- محتوى تعليمي أصلي ومراجع؛ لا نشر آلي لمحتوى غير مُراجع.
- العمل دون اتصال بعد تسجيل الدخول الأول وتوفر حزمة المنهج محليًا: تنزيل أولي للويب، وتضمين كامل في تثبيت Android وWindows.
- لا استخدام لرموز IPA في أي جزء من المنتج.
- لا تسجيل لصوت المتعلم بغرض تقييم النطق، ولا درجات آلية للنطق.
- لا منافسات أو تصنيفات بين المتعلمين.
- حماية الخصوصية وتقليل البيانات غير الضرورية، مع إحصائيات تعليمية تفصيلية مقيدة الصلاحيات للإدارة.

## المنصات المستهدفة

| المنصة | التقنية المستهدفة |
|---|---|
| الويب | React + TypeScript + PWA |
| Android | React + TypeScript + Capacitor |
| Windows | React + TypeScript + Tauri |

## البنية التقنية المستهدفة

- الواجهة: React وTypeScript.
- واجهات API: Hono وTypeScript على Cloudflare Workers.
- قاعدة البيانات المركزية: PostgreSQL عبر Neon.
- الاتصال بـ PostgreSQL من Workers: Hyperdrive عند ملاءمته.
- التخزين المحلي: IndexedDB للويب وSQLite للتطبيقات الأصلية.
- حزم المحتوى: JSON وMarkdown وملفات وسائط مستقلة ضمن ZIP.
- التخزين الكائني: طبقة تجريد قابلة لتبديل المزود. لم يُحسم مزود الإنتاج بعد؛ يجب إثبات أنه مجاني دون بطاقة مصرفية أو فترة تجريبية أو فوترة غير مقصودة.

هذه اختيارات معمارية مستهدفة وليست إثباتًا بأن حدود الخطط المجانية تكفي لكل أعداد المستخدمين.

## الحالة الحالية

فرع `implementation/full-build` يحتوي تنفيذًا أوليًا متكاملًا قيد الإنشاء: Workspace pnpm، واجهة Web/PWA للمعاينة، لوحة إدارة منفصلة، shell أولي لـ Capacitor، حزم domain/schema/curriculum/storage-web، وWorker API مع migration أولي. اجتاز CI بناء الويب والإدارة وفحوص TypeScript والاختبارات والأمان في التشغيل الموثق؛ هذا لا يثبت تشغيل المنصات أو جاهزيتها للإطلاق.

أضيف Windows/Tauri 2 وربط بواجهة `apps/web`، واجتاز اختبار التثبيت والتشغيل على Windows في CI. كما اجتازت H2b-4 التحقق من حزمة fixture الاختبارية المضمّنة ورفض التلاعب بها في التطبيق المثبّت؛ دُمج PR #29 في commit `c09167f14451da0e4630766ad72b657c0609720d`. لا تمثل fixture منهجًا منشورًا ولا تثبت رحلة درس كاملة أو SQLite أو Authenticode. لا يزال `packages/storage-native` هيكلًا بلا Adapter SQLite مكتمل، وH2b-5 لم تُنفذ. أضيفت حزمتا `i18n` و`assessment-engine`، ونواة أولية مستقلة لـ `curriculum-engine` للتحقق من علاقات المتطلبات السابقة وإتاحة الدروس المنشورة؛ لا يعني ذلك اكتمال نظام المنهج. API الحالي معالج Worker يدوي وليس Hono، والمصادقة مغلقة، ولم تُطبق قاعدة البيانات على مزود فعلي. توجد ثلاث مسودات تعليمية غير منشورة ولا توجد حزمة منهج منشورة. CI ما بعد الدمج رقم 179 اكتمل بنجاح في وظيفتي `validate` وWindows؛ كما اكتمل CI رقم 181 على commit الوثائق الحالي بنجاح في الوظيفتين. هذا يثبت نجاح بوابة Windows المحددة في CI، ولا يعني اكتمال Windows أو H2b بالكامل.

ترتيب التنفيذ المعتمد: **Web/PWA وWindows أولًا، ثم Android بعد الاستقرار، ثم تحديث التطبيق التلقائي أخيرًا**. لا يعني ذلك تجاوز بوابات الاختبار أو اعتماد مزود أو حقوق المحتوى أو المراجعة البشرية. راجع [سجل التنفيذ](docs/IMPLEMENTATION-STATUS.md) و[خارطة الطريق](docs/ROADMAP.md) للحصول على الحالة التفصيلية.
