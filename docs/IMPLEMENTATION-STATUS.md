## ما تم إنشاؤه

- Workspace TypeScript مع تطبيق المتعلم Web/PWA وتطبيق إدارة مستقل.
- محرك تعلم مستقل: التصحيح، الإتقان متعدد الأسئلة والسياقات، وجدولة المراجعة بإصدار.
- مخططات درس وحزمة ومنهج؛ فحص المسارات والأحجام والبصمات ومخطط البيانات.
- ثلاث مسودات تعليمية أصلية تمهيدية؛ جميعها غير منشورة ولا يمكن بناؤها كحزمة منشورة قبل سجل مراجعة بشرية.
- تخزين IndexedDB للتقدم المحلي وطابور مزامنة يحتفظ بالعملية حتى إقرار الخادم.
- API Hono مع مصادقة JWT مغلقة عند غياب الإعداد، وتفويض خادمي ونقاط مزامنة وإدارة.
- ترحيل PostgreSQL أولي للحسابات والأدوار والمحتوى والإصدارات والتقدم والمزامنة والتدقيق والجلسات والحذف.
- CI للتحقق من TypeScript والاختبارات والأمان والمحتوى وبناء التطبيقين.

## بوابات لم تُجتز بعد

| المجال | الحالة الحالية | ما يلزم قبل الاعتماد |
|---|---|---|
| CI | أول تشغيل قيد التحقق | حل كل أخطاء build/types/tests/lint فعليًا |
| Web/PWA | بنية أولية | تنزيل حزمة كاملة بعد تسجيل الدخول واختبارات offline/eviction/update فعلية |
| Android | Capacitor shell | SQLite، تضمين الحزمة المنشورة، lifecycle، وبيئة runner/device تتيح H2a/H4 |
| Windows | مؤجل بقرار H2b | لا يبدأ دون شروط runner/toolchain/tamper/Authenticode |
| المصادقة والبريد | مغلقة | مزود لا يتطلب بطاقة أو تجربة أو فوترة غير مقصودة، مع مفاتيح خارج Git |
| PostgreSQL/Hyperdrive | بنية ومخطط فقط | تشغيل migrations وRLS واختبارات الملكية والعزل والنسخ الاحتياطي |
| تخزين الحزم | غير معتمد | مزود مجاني مستوفٍ للشروط أو بديل ذاتي الاستضافة موثق |
| المزامنة | outbox محلي وAPI idempotency أولي | تطبيق الأحداث على حالة التعلم واختبارات التعارض والحذف وجهاز offline |
| لوحة الإدارة | واجهة منفصلة وAPI أولي | دعوات وأدوار وتدقيق واختبارات server authorization |
| المحتوى | مسودات فقط | مراجعة لغوية/تربوية/حقوقية بشرية واعتماد مخول |
| H4 | لم يبدأ | مشروط باكتمال H2a أو قرار تغيير صريح |
| H2a | جزئي تاريخيًا | runner يتيح KVM أو جهاز Android فعلي موثق؛ تثبيت APK وقراءة runtime checksum |
| التبرعات والقانون | غير محسوم | مراجعة قانونية وإدارية قبل التفعيل |

## قيود لا يجوز تجاوزها

- لا أسرار أو كلمات مرور أو مفاتيح توقيع في Git.
- لا تفعيل خدمات مدفوعة أو فترات تجربة أو فوترة تلقائية.
- لا نشر لمسودة تعليمية آلية.
- لا IPA ولا تسجيل أو تقييم صوت المتعلم.
- لا تشغيل للوحة الإدارة داخل حزمة المتعلم.
- لا ادعاء باجتياز مرحلة لم تُشغّل اختبارات قبولها.
