- اجتاز سير إنشاء ملف القفل [41457643542](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41457643542)، ثم أُضيف `pnpm-lock.yaml` في الالتزام `9f0054bd7ad329c3731a924163a1bb79335cca12`.
- توجد تطبيقات Workspace أولية: `apps/web` و`apps/admin` و`apps/android`. لا يوجد مجلد `apps/desktop` ولا تطبيق Tauri حاليًا.

## ما تثبته الشيفرة الحالية

- **Web/PWA:** واجهة React/Vite أولية للمعاينة؛ في الإنتاج تبقى المصادقة مغلقة حتى اعتماد مزود هوية. يوجد Service Worker لقشرة التطبيق والملفات الثابتة، لكن لا يوجد دليل E2E على تنزيل كامل للمنهج أو استمرار رحلة تعلم Offline بعد إغلاق المتصفح وإعادة تشغيله.
- **Admin:** تطبيق React/Vite منفصل بمدخل بناء مستقل وواجهة أولية. لا تثبت الواجهة وحدها اكتمال الدعوات أو إدارة الموظفين أو جميع صلاحيات الخادم.
- **منطق المجال:** `packages/domain` يحتوي حاليًا دوال تصحيح اختيار من متعدد، وتقييم إتقان، وجدولة مراجعة، وتحديد مستوى مشروط بالمعايرة، وفتح مرحلة وخطة علاجية. هذا منطق أولي في حزمة واحدة؛ لا توجد بعد حزمتا `curriculum-engine` و`assessment-engine` مستقلتان، ولا يصح وصف محرك المنهج الكامل بأنه مكتمل.
- **المنهج:** `packages/curriculum` يحتوي ثلاث مسودات فقط وقائمة مراحل ثابتة؛ `publishedLessons` فارغة. لم تُعتمد المسودات بشريًا ولا توجد حزمة منهج منشورة.
- **المخططات:** `packages/content-schema` يحتوي Lesson/Manifest schemas والتحقق من المسارات والحجم وعدد الملفات وبصمات SHA-256. لا يعني ذلك وجود ZIP importer كامل؛ مسار التنزيل الحالي في `storage-web` يدعم ملف `content.json` واحدًا فقط.
- **تخزين الويب:** `packages/storage-web` يوفّر IndexedDB للتقدم والطابور والمراجعات والإعدادات وبيانات الحزم والملفات، مع دوال مزامنة وتنزيل محدودة. لا تزال اختبارات المتصفح الفعلي وفقد التخزين والمساحة والاستعادة والتعارض ناقصة.
- **API:** `services/api` يحتوي معالج Worker يدويًا وواجهات أولية للمصادقة المغلقة والمزامنة وإدارة المحتوى. لا توجد تبعية Hono في `services/api/package.json`؛ لذلك التنفيذ الحالي **ليس Hono** رغم أن Hono هو الهدف المعماري المعتمد. المصادقة ترجع حالة غير مهيأة عند غياب إعداد الهوية، ولم يُعتمد مزود.
- **قاعدة البيانات:** يوجد ترحيل PostgreSQL أولي وسياسات RLS في ملف SQL؛ لم يقدم المستودع دليلًا على تطبيق migration على قاعدة فعلية أو اختبار عزل مستخدمين أو نسخ احتياطي.
- **التخزين الأصلي:** `packages/storage-native` يحتوي تعريف حزمة واعتماديات فقط، بينما مسار export يشير إلى `src/index.ts` غير الموجود في الفرع. لا يوجد Adapter SQLite مكتمل.
- **Android:** يوجد Capacitor shell وإعداداته، لكنه لا يثبت تنفيذ SQLite أو تضمين المنهج المنشور أو دورة حياة التطبيق. نتيجة H2a التاريخية جزئية كما أدناه؛ H4 لم يبدأ.
- **Windows:** لا يوجد تطبيق Tauri أو EXE في الفرع حتى هذه اللقطة. فُتح مسار H2b للتنفيذ بقرار E-14، لكنه لم يُنفذ ولم يُثبت.
- **الحزم والترجمة:** لا توجد حاليًا حزم مستقلة باسم `packages/i18n` أو `packages/curriculum-engine` أو `packages/assessment-engine`.

## بوابات لم تُجتز بعد

| المجال | الحالة المثبتة | المطلوب قبل الاعتماد |
|---|---|---|
| Web/PWA | واجهة أولية وCI build | تنزيل المنهج الكامل، واختبارات browser/Offline/eviction/restore/update |
| Windows | لم يبدأ Tauri/desktop | تطبيق Windows، بناء وتثبيت وتشغيل فعلي، قراءة الحزمة المضمّنة، tamper tests، وتوثيق حالة Authenticode |
| محركات التعلم | دوال أولية في `domain` | فصل واجهات curriculum/assessment، اختبارات وحدات وحدود، وعقود ثابتة قابلة للاستخدام دون اتصال |
| Android | Capacitor shell؛ H2a جزئي | يأتي بعد استقرار Web/Windows؛ SQLite والحزمة المضمّنة وlifecycle ثم H2a/H4 |
| API/Hono | Worker handler يدوي، ليس Hono | تنفيذ Hono وفق القرار المعتمد أو تعديل قرار معماري منفصل؛ اختبارات API وتفويض |
| الهوية والبريد | مغلقان | مزود يثبت عدم البطاقة والاشتراك والفترة التجريبية والفوترة |
| PostgreSQL | مخطط migration فقط | تطبيق migrations واختبارات RLS/الملكية والعزل والنسخ |
| Object Storage | غير معتمد | Adapter ومزود مجاني مستوفٍ للشروط أو بديل موثق |
| المزامنة | outbox محلي وقبول idempotent أولي | تطبيق كل نوع حدث، تعارضات، جهاز Offline، حذف/إبطال واختبارات تكامل |
| لوحة الإدارة | واجهة وAPI أوليان | دعوات وأدوار وتدقيق كامل واختبارات authorization |
| المحتوى | 3 مسودات غير منشورة | مراجعة لغوية/تربوية/حقوقية بشرية واعتماد مخول |
| التحديث التلقائي للتطبيق | لم يبدأ | يبدأ أخيرًا بعد استقرار Web/Windows/Android؛ توقيع/ثقة/تراجع وموافقة المستخدم |
| TTS والتبرعات والقانون | غير محسوم | لا تفعيل قبل إثبات الحقوق والمجانية والمراجعة القانونية |
