# سجل التنفيذ التكاملي — Fluently

**لقطة الحالة:** 2026-11-04  
**الفرع المستهدف:** `implementation/full-build`  
**تفويض التنفيذ:** DECISIONS E-11 (2026-11-01) وE-14 (2026-11-02).  
**الحالة العامة:** تنفيذ جزئي قيد البناء؛ لا يوجد إعلان جاهزية لأي منصة أو إطلاق.

## أدلة البناء والإدارة

- أُعدّ Monorepo باستخدام pnpm `12.16.1` وملف `pnpm-workspace.yaml`، وأُنشئ `pnpm-lock.yaml` بواسطة سير عمل منفصل.
- اجتاز تشغيل CI رقم [41457643533](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41457643533) التثبيت المجمد، وTypeScript، واختبارات الوحدات، وLint، وفحص الأسرار، وتدقيق الاعتماديات، وفحص مسودات المحتوى، وبناء Web وAdmin. هذا دليل CI للالتزام `93128d0868455191864d77af9e0bafddffdffa59`، وليس دليلًا على تشغيل المنصات أو جاهزيتها.
- اجتاز سير إنشاء ملف القفل [41457643542](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41457643542)، ثم أُضيف `pnpm-lock.yaml` في الالتزام `9f0054bd7ad329c3731a924163a1bb79335cca12`.
- توجد تطبيقات Workspace أولية: `apps/web` و`apps/admin` و`apps/android`، وأضيف `apps/desktop` كتطبيق Tauri 2 في PR #26.

## ما تثبته الشيفرة الحالية

- **Web/PWA:** واجهة React/Vite أولية للمعاينة؛ دُمجت حزمة `packages/i18n` في واجهة المتعلم عبر `apps/web`، ويُحفظ اختيار اللغة محليًا وتُضبط `lang` و`dir` وتخطيط الحاوية وفق RTL/LTR. يغطي `apps/web/src/App.test.tsx` التبديل واستعادة لغة إقليمية في jsdom؛ هذا ليس اختبار متصفح فعليًا. أضيف في `packages/storage-web` تنزيل لكل ملفات manifest المعلنة عبر طلبات مصادَق عليها، مع قراءة bounded streams وفحص SHA-256 قبل تفعيل IndexedDB ذريًا. كما أضيف قارئ ZIP32 باستخدام `fflate@0.8.3` في `packages/storage-web/src/curriculum-zip.ts`: يطابق manifest المضمّن مع manifest موثوق خارجي، ويفحص الدليل المركزي والرؤوس المحلية والمسارات والحقوق والأحجام وبصمات الملفات، ويرفض التشفير وZIP64 والروابط والملفات التنفيذية والبيانات غير المفسرة. يمكن فحص حجم `Blob` قبل القراءة إلى الذاكرة. تغطي الاختبارات STORE وDEFLATE وحالات ZIP تالفة/خطرة وبقاء الإصدار النشط قبل التفعيل. أضيف في `services/api/src/curriculum-package.ts` منشئ ZIP32 لإصدار `manifest.json` و`content.json` وملف JSON مستقل لكل درس مع بصمات SHA-256، مع رفض الدروس غير المعتمدة أو ناقصة الحقوق. مسار تجهيز الإصدار يخزن الملفات والأرشيف وبصمته، ومسار النشر يعيد فحص كل ملف قبل نقل الإصدار، وتتوفر نقطة تنزيل محمية `/v1/curriculum/package.zip`. هذا لا يعني وجود حزمة منشورة فعلًا: لا توجد دروس معتمدة حاليًا، والمصادقة الإنتاجية مغلقة. وصل مسار الاستعادة بعد تسجيل الدخول في `apps/web/src/App.tsx` بتنزيل ZIP الموثوق وتفعيله ذريًا، مع رجوع إلى النقل القديم متعدد الملفات إذا لم تتوفر نسخة ZIP. يقدّر `preflightCurriculumStorage` المساحة المتاحة قبل تنزيل ملفات الحزمة، ويتوقف عند ثبوت عدم كفايتها ويعرض واجهة عربية/إنجليزية بالمطلوب والمتاح؛ إذا لم تتوفر واجهة تقدير المساحة يستمر التنزيل. تعرض الواجهة تقدم البايتات أثناء تنزيل ZIP أو النقل القديم، مع نسبة مئوية عندما يرسل الخادم حجمًا موثوقًا. لا توجد رحلة قبول في متصفح فعلي/Offline كاملة أو تحقق دلالي لكل JSON بعد الاستيراد. رخصة الاعتماد مسجلة في `THIRD-PARTY-NOTICES.md`. في الإنتاج تبقى المصادقة مغلقة حتى اعتماد مزود هوية. يوجد Service Worker لقشرة التطبيق والملفات الثابتة.
- **Admin:** تطبيق React/Vite منفصل بمدخل بناء مستقل وواجهة أولية؛ تكاملت معه حزمة `packages/i18n` لعرض العربية والإنجليزية وضبط RTL/LTR واستعادة اللغة المحفوظة، مع اختبارات jsdom. لا تثبت الواجهة وحدها اكتمال الدعوات أو إدارة الموظفين أو جميع صلاحيات الخادم، وتظل المصادقة غير مفعّلة للإنتاج.
- **منطق المجال والتقييم:** أُنشئت `packages/assessment-engine` كحزمة TypeScript مستقلة لتصحيح الاختيار والإجابة النصية وفق سياسة تطبيع يمررها المستدعي، وإرجاع التغذية الراجعة والأمثلة العلاجية، وإظهار التلميحات تدريجيًا، وحساب الإتقان وتحديد المستوى وفتح المرحلة والخطة العلاجية. `packages/domain` يعيد تصدير واجهات التقييم للحفاظ على التوافق، بينما تبقى جدولة المراجعة والمزامنة داخله. يحتسب الإتقان آخر محاولة لكل معرّف سؤال مرة واحدة؛ شروط الأدلة والحدود تأتي من الإعدادات ولا توجد افتراضات رقمية مضمّنة؛ تتطلب معايرة تحديد المستوى عتبات وعدد إجابات وتنوع سياقات لكل مرحلة/مهارة، ويُحسب معدل كل مرحلة من أدلتها الخاصة دون القفز فوق مرحلة فاشلة. `speaking-practice` مستبعد من المهارات القابلة للقياس. الحزمة لا تمثل بعد نظامًا تربويًا معتمدًا: يلزم إعداد مخططات وأسئلة جديدة ومعايرة بشرية وتكامل واختبار على مستوى التطبيق.
- **محرك المنهج:** دُمجت حزمة `packages/curriculum-engine` في [PR #5](https://github.com/ammarcharef06/Fluently-EH/pull/5). تجمع الدروس وتتحقق من معرفاتها وعلاقات المتطلبات السابقة وكشف الدورات، وتحدد إتاحة الدرس المنشور بناءً على معرّفات متطلبات سبق استيفاؤها. رُبطت ببيانات `packages/curriculum` الحالية. اجتاز تشغيل CI بعد الدمج [41474010494](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41474010494) فحوص TypeScript والاختبارات وLint والأمان والاعتماديات والمحتوى وبناء Web/Admin. أُحدّث ملف القفل بالالتزام `32599cc4f8a834402dbf3d2b957d6799fdbc8a32`. هذه نواة أولية فقط؛ لا تحسب الإتقان أو تحدد مستويات CEFR أو تنشر محتوى، ولا تثبت اكتمال تنزيل ZIP أو العمل دون اتصال أو محرك المنهج الكامل.
- **المنهج:** `packages/curriculum` يحتوي ثلاث مسودات فقط وقائمة مراحل ثابتة؛ `publishedLessons` فارغة. لم تُعتمد المسودات بشريًا ولا توجد حزمة منهج منشورة.
- **المخططات:** `packages/content-schema` يحتوي Lesson/Manifest schemas والتحقق من المسارات والحجم وعدد الملفات وبصمات SHA-256. لا يعني ذلك وجود ZIP importer كامل؛ مسار التنزيل الحالي في `storage-web` يدعم ملف `content.json` واحدًا فقط.
- **تخزين الويب:** `packages/storage-web` يوفّر IndexedDB للتقدم والطابور والمراجعات والإعدادات وبيانات الحزم والملفات، مع دوال مزامنة وتنزيل محدودة. لا تزال اختبارات المتصفح الفعلي وفقد التخزين والمساحة والاستعادة والتعارض ناقصة.
- **API:** `services/api` يحتوي معالج Worker يدويًا وواجهات أولية للمصادقة المغلقة والمزامنة وإدارة المحتوى. لا توجد تبعية Hono في `services/api/package.json`؛ لذلك التنفيذ الحالي **ليس Hono** رغم أن Hono هو الهدف المعماري المعتمد. المصادقة ترجع حالة غير مهيأة عند غياب إعداد الهوية، ولم يُعتمد مزود.
- **قاعدة البيانات:** يوجد ترحيل PostgreSQL أولي وسياسات RLS في ملف SQL؛ لم يقدم المستودع دليلًا على تطبيق migration على قاعدة فعلية أو اختبار عزل مستخدمين أو نسخ احتياطي.
- **التخزين الأصلي:** على Windows، يوجد تنفيذ SQLite داخل Rust/Tauri مع هوية متعلم محلية UUID v4 وأوامر تقدم لا تقبل learner_id من WebView؛ ربط save/read/list واستيراد IndexedDB القديم مرة واحدة ضمن معاملة SQLite مضاف في PR #43. اجتاز commit `4c860fcb2621ee8a456277ff2d3dcf841cd9efbd` في CI run 41895489180 (run 244) وظيفتي `validate` و`H2b Windows build, install and runtime smoke`، بما يشمل Cargo tests وWindows build/install/launch وfixture tamper smoke. هذا لا يثبت رحلة درس فعلية عبر UI أو العمل Offline بعد إعادة تشغيل التطبيق. `packages/storage-native` لا يزال حزمة Capacitor/Android منفصلة غير مكتملة، ولا يُعد تنفيذ Windows بديلًا عن Adapter Android.
- **Android:** يوجد Capacitor shell وإعداداته، لكنه لا يثبت تنفيذ SQLite أو تضمين المنهج المنشور أو دورة حياة التطبيق. نتيجة H2a التاريخية جزئية كما أدناه؛ H4 لم يبدأ.
- **Windows:** أضيف هيكل Tauri 2 وربطه بواجهة `apps/web`. اجتاز NSIS install/launch smoke على `windows-2025` في CI run [41675891966](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41675891966)، ودُمج PR #27 في `2968db1d6bfa0408bdaaeb1689fbc339553e55d7`. اكتمل تنفيذ H2b-4 عبر PR #29 ودُمج في `c09167f14451da0e4630766ad72b657c0609720d`. أثبت CI run [41703166428](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41703166428) (run 178) بناء Windows QA وتثبيته وتشغيله بالحزمة السليمة، وخروج التطبيق برمز 1 بعد تغيير بايت واحد من ملف الدرس المثبت، ثم نجاح التشغيل بعد استعادة الملف الأصلي. المراجعة الفنية المستقلة لم تجد مانع قبول ضمن نطاق H2b-4. الحزمة fixture اختبارية غير منشورة؛ الاختبار لا يثبت المنهج المنشور أو رحلة درس كاملة أو SQLite أو Authenticode، ولا يحمي SHA-256 المثبت داخل executable من استبدال executable نفسه. CI ما بعد الدمج run [41708362480](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41708362480) (run 179) اكتمل بنجاح في وظيفتي `validate` وWindows. كما نجح CI run [41709153946](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41709153946) (run 181، المحاولة الثانية) على commit أقدم `aaadcc8489f76d8bce5604301c2cb5b25f7c4e86` في الوظيفتين. ثم اجتاز إصلاح مهلة اختبار tamper في PR #31 CI run [41723727182](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41723727182) (run 186) في `validate` وWindows، ودُمج في `de29dad0c7039214795985eb5ffcc7c8e83f7c83`. دُمج H2b-5/SQLite عبر PR #33 في `752c5bfca0592b4d61d3e4be6987b1e70e5d88a8`: قاعدة SQLite محلية بمخطط versioned وأوامر Tauri للحفظ وقراءة تقدم درس واحد، مع اختبارات schema/versioning والعزل على مستوى المفتاح وupsert والمدخلات والاستمرارية بعد إعادة فتح القاعدة. لا يزال اختبار التطبيق المثبّت الذي يحفظ تقدم رحلة درس كاملة ثم يستعيدها Offline غير مثبت. ثم دُمج H2b-6a عبر PR #38 في `51ee38fabc5df1e10ff282bd2f3b69317ccca2ef`: إضافة قراءة قائمة تقدم المتعلم بترتيب ثابت والتحقق من معرّفات learner/lesson واختبارات قائمة النتائج والعزل والمدخلات. CI run [41873829848](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41873829848) اجتاز `validate` وWindows build/install/runtime smoke، لكنه لم يختبر حفظ SQLite من واجهة التطبيق. يضيف PR #43 هوية UUID v4 داخل Rust وSQLite، ويزيل learner_id من مدخلات WebView، ويضيف حاجزًا يمنع save/read/list قبل اكتمال استيراد IndexedDB مرة واحدة؛ كما يرحّل schema إلى v2، ويحفظ سجلات SQLite القديمة، ويمسح التقدم والهوية في أمر حذف البيانات المحلية. يبقى مزود الهوية السحابي غير معتمد، وتعيد المصادقة 503 عند غياب إعداداته؛ الهوية المحلية ليست مصادقة حساب. الهوية المحلية لا تفعّل وحدها واجهة ضيف: `apps/web/src/App.tsx` يبقي إصدار الإنتاج عند شاشة الدخول ما لم تنجح `/api/v1/me` أو تُستعد جلسة حديثة مع حزمة محلية صالحة. لا توجد حزمة منهج معتمدة/منشورة في المستودع حاليًا، ولذلك لا يمكن إثبات رحلة درس غير مسجل فعلية بعد. هذه النتائج لا تعني اكتمال Windows أو H2b أو رحلة تعلم Offline كاملة.
- **الحزم المشتركة:** `packages/curriculum-engine` نواة أولية مدمجة عبر PR #5. دُمجت `packages/i18n` عبر PR #9 وتكاملت الآن مع واجهتي `apps/web` و`apps/admin`؛ تغطي اختبارات jsdom تبديل اللغة واستعادة التفضيل وتحديث lang/dir، بينما تظل اختبارات المتصفح الفعلية مفتوحة. دُمجت نواة `packages/assessment-engine` عبر PR #11 واجتازت CI run [41479100420](https://github.com/ammarcharef06/Fluently-EH/actions/runs/41479100420). أُضيف اعتماد مباشر لمحرك التقييم في `apps/web` لتصحيح خطوات الاختيار الموجودة، مع اختبار تدفق على مسودة الضمائر؛ يظل هذا تكاملًا جزئيًا للتصحيح والتغذية الراجعة فقط. مخطط المحتوى الحالي لا يتضمن hints أو أمثلة علاجية أو بيانات remedial، ولا توجد مخططات إتقان/معايرة إنتاجية معتمدة؛ لذلك لم يُفعّل text grading أو hints أو mastery أو placement في واجهة المتعلم.
