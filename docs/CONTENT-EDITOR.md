# مواصفات محرر المحتوى — Fluently

## 1. الغرض
محرر داخل لوحة الإدارة يجمع المحرر المرئي والحقول المنظمة والتحرير المتقدم، مع معاينة المتعلم والقوالب وإدارة الإصدارات والاستيراد والتصدير. لا تمنح أدوات التحرير صلاحية النشر تلقائيًا.

## 2. الأدوار
- **المدير الرئيسي:** الموظفون والدعوات والأدوار والقوالب وسجل التدقيق وإدارة الحزم.
- **المحرر:** إنشاء المسودات وتحريرها واستخدام القوالب وإرسالها للمراجعة.
- **المراجع:** مراجعة وإضافة ملاحظات واعتماد أو طلب تعديل ضمن صلاحياته.
- **مسؤول النشر:** إنشاء الحزم وفحصها ونشر الإصدارات أو التراجع عنها.

كل صلاحية تُفرض في الخادم، لا عبر إخفاء عناصر الواجهة.

## 3. وظائف المحرر
- شجرة للمسارات والمراحل والمستويات والوحدات والدروس.
- بحث وتصفية حسب النوع والمستوى والمهارة والحالة.
- محرر مرئي وحقول منظمة.
- تحرير متقدم لتمثيل البيانات المنظم بعد التحقق من المخطط.
- معاينة كما ستظهر للمتعلم.
- إدارة مسودات ونسخ وإصدارات.

## 4. الكتل التعليمية
- عنوان وفقرة ونص.
- ملاحظة وتنبيه.
- مثال صحيح أو خطأ شائع.
- جدول وصورة مع وصف بديل.
- صوت مع النص المرتبط.
- حوار أو نص قراءة.
- قاعدة أو بطاقة مفردة.
- تمرين أو سؤال.
- عنصر تفاعلي من الأنواع المعتمدة.

لا يسمح بتنفيذ HTML أو JavaScript اعتباطي داخل حزم الدروس.

## 5. القوالب
قوالب للحروف والصوتيات والقراءة والقواعد والمفردات والاستماع والحوار والكتابة والمراجعة والاختبارات. يمكن للمسؤول المخول إنشاء قالب أو نسخه أو تعديل حقوله وإصداره. تغيير القالب لا يغير الدروس المنشورة القديمة تلقائيًا.

## 6. بنك الأسئلة
- إنشاء وتحرير الأسئلة وحفظها ضمن المنهج وبنك مركزي بمعرف ثابت.
- تصنيف المستوى والمهارة والصعوبة والموضوع والهدف.
- إعادة استخدام السؤال دون نسخ نسخ متعارضة.
- تحديد الإجابة والتفسير والتلميحات.
- معاينة السؤال.
- تحذير من التشابه والتكرار.
- بناء مخططات اختبارات من البنك.

الأنواع المخططة: اختيار، صح/خطأ، فراغ، ترتيب، توصيل، إجابة قصيرة، تهجئة، قراءة، استماع، ترجمة موجهة، وموقف تطبيقي.

طريقة إدخال السؤال قد تكون يدوية أو عبر حقول المحرر؛ لم يُعتمد مولد أسئلة مستقل. يمكن للأدوات الذكية اقتراح مسودات فقط وفق قرار المنتج.

## 7. إدارة الصوت
- إدخال النص المصدر.
- اختيار الصوت الأمريكي الرجالي أو النسائي.
- توليد الملف مسبقًا.
- معاينة ومقارنة النص بالصوت.
- فحوص آلية للملف.
- إرسال للمراجعة البشرية.
- اعتماد الملف وربطه بمكتبة مشتركة أو درس/حوار/قصة.

لا توجد وظيفة لتسجيل صوت المتعلم أو تقييمه.

## 8. إدارة الوسائط
- رفع الملفات والتحقق من النوع والحجم والبصمة.
- أوصاف بديلة للصور.
- ربط الأصل بمكتبة مشتركة.
- كشف الملفات المتكررة وغير المستخدمة.
- التحقق من حقوق إعادة التوزيع قبل وضع الأصل في حزمة.
- منع المسارات غير المصرح بها.

## 9. الفحوص الآلية
- صلاحية مخطط البيانات والحقول المطلوبة.
- عدم تكرار المعرفات.
- صحة مراجع الوسائط.
- وجود إجابة أو معيار تصحيح.
- روابط غير مكسورة.
- تنبيه إلى التكرار المحتمل.
- وجود نواتج تعلم.
- فحص مخالفة حظر IPA.

هذه الفحوص لا تثبت جودة الشرح أو صحة اللغة؛ يلزم التحقق البشري.

## 10. دورة النشر
1. إنشاء مسودة.
2. تحرير المحتوى والوسائط.
3. فحوص آلية.
4. إرسال للمراجعة.
5. إضافة ملاحظات أو طلب تعديل.
6. تعديل المسودة.
7. اعتماد من الدور البشري المخول.
8. إنشاء إصدار.
9. فحص الحزمة واختبارها.
10. نشرها بواسطة مسؤول النشر.
11. متابعة الإصدار وإمكانية التراجع.

تُحفظ حالة المراجعة والملاحظات وهوية أصحاب الإجراءات والتوقيت مع بيانات إصدار المحتوى. لا ينشر النظام محتوى تعليميًا تلقائيًا.

## 11. حزم ZIP
تحتوي على manifest وJSON وMarkdown والصور والصوتيات وبيانات الإصدارات والتبعيات والحقوق اللازمة.

عند الاستيراد:
- لا تُنفذ ملفات أو شيفرات من الأرشيف.
- تمنع مسارات اجتياز المجلدات.
- تتحقق الأنواع والأحجام وعدد الملفات والبصمات والمخططات.
- تُعرض التغييرات قبل التطبيق.
- تدخل العناصر إلى مساحة المسودات أولًا.

عند التصدير:
- لا تُصدر أسرار أو بيانات متعلم.
- تحفظ المعرفات والإصدارات.
- تُرفق إشعارات الحقوق المطلوبة.

## 12. الإصدارات
- المسودة قابلة للتعديل.
- الإصدار المنشور لا يتغير بصمت.
- كل تعديل مؤثر ينشئ إصدارًا جديدًا.
- يُختبر الإصدار قبل النشر.
- تحفظ الإصدارات المنشورة والتراجع.
- تظهر ملاحظات التحديث رقم الإصدار والحجم والتغييرات.
- لا يحتاج تحديث المحتوى إلى إعادة تثبيت التطبيق إلا إذا تطلب تغير المخطط أو المنطق ذلك.

## 13. الذكاء الاصطناعي
يُسمح باقتراح أمثلة وتمارين وصيغ شرح أولية فقط. كل ناتج مسودة. لا اعتماد أو نشر تلقائي، ولا اختراع مراجع، ولا تجاوز مراجعة الحقوق.

## 14. معايير القبول
- إنشاء درس دون كتابة كود.
- معاينة المتعلم.
- التحقق من الحقول والمخططات.
- عدم نشر محتوى غير معتمد.
- إعادة استخدام السؤال بمعرفه.
- رفض الحزم غير الصالحة أو المشبوهة.
- عدم تنفيذ ملفات ZIP.
- استرجاع إصدار سابق.
- تتبع كل إجراء إداري.
