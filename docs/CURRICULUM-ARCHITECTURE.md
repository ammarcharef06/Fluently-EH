# معمارية المنهج التعليمي — Fluently

**الحالة:** مواصفة تأسيسية؛ لا تعني أن المحتوى الكامل قد كُتب أو نُشر.

## 1. مبادئ التصميم
- يبدأ المسار من شخص لا يعرف الحروف الإنجليزية.
- تُستخدم أوصاف CEFR مرجعًا لنواتج التواصل من Pre-A1 إلى C2، مع مرحلة تأسيسية لمحو الأمية قبل Pre-A1.
- إكمال الدرس لا يساوي الإتقان؛ يلزم تطبيق متكرر في سياقات جديدة.
- العربية الفصحى المبسطة لغة الشرح الأولية، والإنجليزية الأمريكية نموذج التعلم.
- تُقدم القراءة والكتابة أولًا، مع تعريض المتعلم للصوت والاستماع تدريجيًا.
- لا IPA في أي مرحلة أو ملف أو واجهة.
- لا تسجيل لصوت المتعلم بغرض التقييم، ولا درجة نطق آلية.
- لا تُستخدم ترجمة حرفية تغير معنى التعبير.

## 2. الهيكل الهرمي
`Program → Pathway → Stage/CEFR Level → Unit → Lesson → Activity → Item`

- البرنامج: المنهج الكلي.
- المسار: المسار الرئيسي أو مسار فرعي اختياري.
- المرحلة/المستوى: المرحلة التأسيسية أو مستوى CEFR.
- الوحدة: مجموعة أهداف مترابطة.
- الدرس: وحدة تعلم قصيرة، عادة 10–15 دقيقة.
- النشاط: شرح أو مثال أو تمرين أو قراءة أو استماع أو مراجعة.
- العنصر: سؤال أو كلمة أو مثال أو ملف وسائط.

يملك كل كيان معرفًا ثابتًا مستقلًا عن عنوانه وموضعه.

## 3. المسارات
**المسار الرئيسي:** من محو الأمية إلى C2 ويغطي القراءة والكتابة والاستماع والتحدث والمفردات والقواعد والتواصل.

**مسارات فرعية اختيارية:** الإنجليزية الأكاديمية والمهنية والمحادثة والتحضير لمهارات اختبارات خارجية. لا تصدر هذه المسارات شهادات اعتماد، ولا تستبدل المسار الرئيسي. لكل مسار متطلبات دخول واضحة.

## 4. مرحلة محو الأمية قبل Pre-A1
نواتجها:
- التعرف إلى الحروف الكبيرة والصغيرة معًا.
- التمييز بين اسم الحرف وصوته.
- ربط الحروف بالأصوات الأساسية.
- دمج الأصوات وفك كلمات غير محفوظة مسبقًا.
- تعلم الأنماط المنتظمة قبل الاستثناءات.
- تعلم الحروف المركبة تدريجيًا مثل sh وch وth وee وph.
- قراءة وتهجئة كلمات وعبارات وجمل قصيرة.
- الكتابة عبر لوحة المفاتيح.
- فهم المسافات وعلامات الترقيم الأولية.

تسلسل تدريس مقترح: شكل الحرف، اسمه وصوته، الدمج، الأنماط الشائعة، الحروف المركبة، الكلمات، الاستثناءات، العبارات والجمل، التهجئة وعلامات الترقيم. يراجع هذا التسلسل وفق نتائج التجريب التعليمي.

## 5. مستويات CEFR ونواتجها العامة
هذه أوصاف تنظيمية موجزة؛ يجب الرجوع إلى مراجع CEFR التفصيلية عند تأليف نواتج كل مستوى.

- **Pre-A1:** كلمات وعبارات مألوفة جدًا، وتعليمات بسيطة، وتبادل معلومات أساسية بدعم.
- **A1:** عبارات يومية مألوفة، تقديم الذات، أسئلة وأجوبة قصيرة، قراءة وكتابة شديدة البساطة.
- **A2:** مهام يومية مباشرة، وصف البيئة والاحتياجات، فهم رسائل ونصوص قصيرة، كتابة ملاحظات بسيطة.
- **B1:** فهم النقاط الرئيسية في موضوعات مألوفة، التعامل مع مواقف السفر والعمل والدراسة، نصوص مترابطة بسيطة.
- **B2:** فهم نصوص أكثر تعقيدًا، تفاعل بطلاقة وعفوية مناسبة، إنتاج نص واضح ومفصل ومناقشة الآراء.
- **C1:** فهم نصوص طويلة ومعقدة والمعاني الضمنية، استخدام مرن للغة في السياقات الاجتماعية والأكاديمية والمهنية.
- **C2:** فهم شبه كل ما يسمع أو يقرأ، تلخيص مصادر متعددة، والتعبير الدقيق عن فروق المعنى.

لا يُعامل المستوى على أنه قائمة قواعد أو كلمات فقط؛ يجب أن يصف أداءً تواصليًا قابلًا للملاحظة.

## 6. خريطة المهارات
ترتبط كل وحدة بمهارة رئيسية ومهارات مساندة:
- القراءة.
- الكتابة.
- الاستماع.
- التحدث والتفاعل.
- المفردات والتراكيب.
- القواعد.
- الوعي الصوتي والنطق.
- الفهم السياقي والوظيفي.

**قيد التحدث:** يجوز تقديم تسجيلات نموذجية وحوارات وتمارين تكرار وتقليد ذاتي. لا يسجل النظام صوت المتعلم ولا يحلله ولا يمنحه درجة آلية. يمكن تسجيل إنجاز النشاط فقط، لا صحة النطق.

## 7. بناء الوحدة والدرس
كل وحدة تتضمن عنوانًا وموضوعًا ومستوى ونواتج تعلم ومتطلبات سابقة ومفردات/تراكيب وأنشطة وتقييمًا ومراجعة لاحقة.

كل درس:
- يركز على هدف محدود واضح.
- يستهدف عادة 10–15 دقيقة.
- يتكون من خطوات متتابعة مع الرجوع.
- يختلف تخطيطه حسب المهارة.
- لا يحشر جميع أنواع الأنشطة في كل درس.
- يتضمن تطبيقًا أو تحققًا مناسبًا للهدف.

أنواع الدروس تشمل الأساسية والتطبيقية والإثرائية والمراجعات والاختبارات.

## 8. المفردات والقواعد
- تحدد أهداف الكلمات النشطة لكل وحدة ومستوى بعد بناء قوائم موثوقة.
- تُفضل العبارات الواقعية مع الكلمة المفردة عند الحاجة.
- بطاقة المفردة تعرض المعنى في السياق والمثال والصوت الأمريكي والاستخدامات الشائعة والروابط ذات الصلة.
- لا يُفترض أن للكلمة ترجمة عربية واحدة ثابتة.
- لكل قاعدة درس مستقل يشرح الوظيفة والتركيب والاستخدام والأخطاء الشائعة والاستثناءات المناسبة للمستوى، ثم يربطها بالنصوص والحوارات.

## 9. المراجعة المتباعدة
يخزن لكل عنصر قابل للمراجعة: معرفه، أداء المتعلم، مرات النجاح والإخفاق، الصعوبة المقدرة، مستوى الإتقان، وموعد المراجعة التالي. تحدد الخوارزمية المواعيد بناء على الأداء والصعوبة، وتعمل دون اتصال، وتملك إصدارًا واضحًا قابلًا للاختبار والتغيير.

## 10. بوابات الإتقان والانتقال
لا يُفتح المستوى بمجرد إكمال المحتوى. يلزم:
- إكمال المتطلبات السابقة أو إثبات إتقانها تشخيصيًا.
- اختبار وفق مخطط إصدار معتمد.
- أسئلة جديدة أو بدائل مكافئة.
- نجاح متكرر وتطبيق في سياق مختلف.
- تحقيق الحدود المحددة مسبقًا لكل مهارة أساسية.

حدود النجاح ليست رقمًا واحدًا لكل شيء؛ تحدد لكل اختبار ومهارة قبل النشر ولا تعدّل بأثر رجعي للمحاولات السابقة.

## 11. التخصيص والتجاوز
يختار المتعلم البدء من الصفر أو إجراء تحديد مستوى. ويمكنه تجاوز محتوى بعد اختبار تشخيصي معتمد يغطي الهدف ومتطلباته، مع حفظ الحالة بوصفها إتقانًا مثبتًا لا درسًا تمت مشاهدته. يحصل المتعثر على خطة علاجية ويستطيع تعديل هدفه اليومي ووتيرة الدراسة.

## 12. مواصفة بيانات المنهج
كل كيان: `id` ثابت، `type`، عنوان وترتيب، مستوى ومهارات، نواتج تعلم، متطلبات سابقة، إصدار، حالة نشر، معرفات وسائط، ومصدر/بيانات حقوق لازمة للأصول الخارجية. تُفحص الحزم بمخططات معروفة وترفض الحزم غير المتوافقة.

## 13. حزم المنهج
ZIP بإصدار واضح يحتوي:
- manifest يحدد المعرف والإصدار والمتطلبات والملفات والأحجام والبصمات.
- JSON للبيانات المنظمة.
- Markdown للشروحات.
- صور وصوتيات مستقلة.
- بيانات الحقوق والإشعارات المطلوبة.
- دعم فحص السلامة والاستيراد والتراجع.

## 14. ما لم يحدد بعد
عدد المراحل الداخلية والوحدات والدروس والكلمات، الحدود الرقمية لكل اختبار، الخوارزمية النهائية للمراجعة، المراجع التعليمية التفصيلية، محرك TTS، ومتطلبات الأجهزة الدنيا. لا تُخترع هذه القيم داخل التنفيذ؛ تُعتمد بعد بناء المحتوى والاختبار.
