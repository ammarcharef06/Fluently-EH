# خارطة طريق Fluently

**هذه خارطة مراحل وليست جدولًا زمنيًا.** لا تُعتمد تقديرات مدة قبل تقدير حجم العمل وتوفر الموارد.

## المرحلة 0 — وثائق الأساس
**الحالة:** الدفعتان الأولى والثانية أُنشئتا. الدفعة الثالثة قيد الإكمال.

المخرجات:
- README وAGENTS والتراخيص وCONTRIBUTING.
- ميثاق المشروع وPRD وسجل القرارات.
- معمارية المنهج والتقييم ومعايير المحتوى ومحرر المحتوى وتجربة المستخدم.
- معمارية النظام والعمل دون اتصال والأمان والبنية والتكاليف والإصدارات وخارطة الطريق ومصفوفة التتبع.

بوابة الخروج:
- اكتمال الوثائق.
- مراجعة التناقضات.
- تمييز القرارات المعتمدة عن غير المحسومة.
- اعتماد مالك المشروع للدفعة.

## المرحلة 1 — إثبات الجدوى التقنية
لا يبدأ بناء منتج كامل. تُبنى نماذج تقنية صغيرة لاختبار:
- React + TypeScript مع PWA وCapacitor وTauri.
- Hono Workers مع PostgreSQL عبر Hyperdrive.
- IndexedDB وSQLite والتخزين المحلي.
- تنزيل ZIP والتحقق من manifest والبصمات.
- العمل دون اتصال والمزامنة idempotent.
- مزود ملفات مجاني دون بطاقة أو فوترة غير مقصودة.
- بريد التحقق والاستعادة.
- توليد صوت أمريكي رجالي ونسائي بترخيص يسمح بالتوزيع.
- حجم حزمة تأسيسية واقعي.

بوابة الخروج:
- نتائج قياس موثقة.
- لا خدمة أساسية تعتمد على فترة تجريبية.
- قرار بشأن مزودي الهوية والبريد والتخزين وTTS.
- تسجيل قرارات ADR.

## المرحلة 2 — أساس المستودع والبنية
- إنشاء Monorepo.
- إعداد TypeScript وlint/format/test.
- إعداد تطبيقات المنصات وهياكلها.
- بناء API الأساسية.
- إعداد PostgreSQL migrations.
- إعداد مخططات JSON.
- إعداد CI والتحقق من التبعيات.
- إعداد إدارة الأسرار خارج المستودع.

بوابة الخروج:
- builds قابلة للتكرار.
- الاختبارات تعمل.
- لا أسرار في المستودع.
- إصدارات أولية لكل منصة.

## المرحلة 3 — الحسابات والبيانات
- مصادقة Google والبريد بعد اعتماد مزود مجاني مناسب.
- التحقق واستعادة الحساب.
- الملفات الشخصية.
- أدوار الإدارة.
- سياسات الوصول.
- تصدير وحذف الحساب.
- قواعد البيانات المحلية والمركزية.

بوابة الخروج:
- إثبات المصادقة والتفويض والحذف.
- لا وصول أفقي بين حسابات المتعلمين.

## المرحلة 4 — محرك المنهج والحزم
- مخططات البرامج والمسارات والمستويات والوحدات والدروس.
- manifest وZIP.
- تنزيل وتحقق وتفعيل ذري للحزمة.
- إصدار المحتوى والتوافق.
- مكتبة الصوت والوسائط.

بوابة الخروج:
- حزمة تأسيسية تجريبية تُثبت وتعمل دون اتصال.
- نجاح التحقق والتراجع.

## المرحلة 5 — تجربة المتعلم الأساسية
- شاشة البداية.
- تحديد المسار/المستوى.
- لوحة المتعلم.
- مشغل الدرس.
- التمارين.
- حفظ التقدم المحلي.
- إعدادات اللغة والصوت والمظهر.
- عرض حالة Offline.

بوابة الخروج:
- إكمال رحلة تعليمية كاملة دون اتصال بعد التنزيل.

## المرحلة 6 — التقييم والإتقان والمراجعة
- بنك الأسئلة.
- التقييم التكويني واختبارات الوحدة.
- تحديد المستوى.
- معايير الإتقان.
- الخطط العلاجية.
- المراجعة المتباعدة.
- التقارير.

بوابة الخروج:
- إثبات أن الأسئلة الجديدة تميز الفهم عن الحفظ.
- لا تقييم صوتي آلي.

## المرحلة 7 — لوحة الإدارة ومحرر المحتوى
- محرر مرئي وحقول منظمة.
- القوالب.
- بنك الأسئلة.
- إدارة الصوت.
- المراجعة وحالات المحتوى.
- سجل التدقيق.
- إنشاء الحزم والنشر والتراجع.
- مركز الدعم والبلاغات.

بوابة الخروج:
- إنشاء ونشر حزمة من لوحة الإدارة دون تعديل شيفرة التطبيق.

## المرحلة 8 — المحتوى التعليمي
يُؤلف المحتوى بمسار مراجعة منظم:
1. مرحلة محو الأمية.
2. Pre-A1.
3. A1.
4. A2.
5. B1.
6. B2.
7. C1.
8. C2.
9. المسارات الفرعية.

لا يُعلن مستوى منشورًا قبل مراجعة تغطي أهدافه ومحتواه واختباراته ووسائطه.

## المرحلة 9 — المزامنة والنسخ
- طابور العمليات.
- منع التكرار.
- دمج الأحداث.
- حل التعارض.
- مزامنة الأجهزة.
- النسخ السحابي الاختياري.
- التصدير والاستعادة.

بوابة الخروج:
- اختبارات فقد الاتصال وإعادة الإرسال والتعارض والحذف تنجح دون فقد صامت.

## المرحلة 10 — الصقل والإطلاق
- اختبارات أمن وأداء وإمكانية وصول.
- متطلبات الأجهزة.
- بناء APK وEXE وPWA.
- التوقيع والتوزيع.
- دليل المستخدم.
- سياسات الخصوصية والحقوق.
- قناة بلاغات.
- تقارير مصروفات التبرعات إذا فُعلت.

## المرحلة 11 — الإصدارات والتوسع
- نشر المراحل تدريجيًا.
- تحسين الأداء والمساحة.
- إضافة المسارات الفرعية.
- مراجعة الحدود المجانية بانتظام.
- نقل الخدمات عند تغير الشروط.
- مساهمات المجتمع مع مراجعة إلزامية.

## قواعد الخارطة
- لا تتخطى بوابة مرحلة لأن الواجهة تبدو مكتملة.
- لا تنشر محتوى لم يراجع.
- لا تبدأ محتوى C2 قبل بناء نظام المحتوى والمراجعة والاختبار.
- لا تربط المنتج بمزود لا يمكن نقله.
- كل مرحلة لها مخرجات قابلة للتحقق واختبارات قبول.
