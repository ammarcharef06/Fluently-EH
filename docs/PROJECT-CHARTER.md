# ميثاق مشروع Fluently

## 1. الغرض

بناء منصة تعليم إنجليزية مجانية للناطقين بالعربية، تبدأ من متعلم لا يعرف الحروف الإنجليزية، وتنقله عبر منهج متدرج حتى مستوى C2 وفق CEFR، مع تأسيس داخلي مفصل يسبق A1.

## 2. الجمهور

- الناطقون بالعربية من مختلف الأعمار.
- المبتدئون تمامًا، ومن لديهم معرفة سابقة ويريدون تحديد مستوى البداية.
- يمكن للمتعلم البدء من الصفر أو إجراء اختبار تحديد مستوى.
- واجهة واحدة لجميع الأعمار.
- الفئة العمرية معلومات اختيارية؛ تُطبّق متطلبات موافقة ولي الأمر حيث يفرض القانون ذلك.

## 3. الوعد التعليمي

Fluently لا يَعِد بالطلاقة في مدة ثابتة، ولا يساوي بين إكمال الدروس وإتقان اللغة. الانتقال يعتمد على أدلة إتقان متكررة وتطبيق في سياقات جديدة.

## 4. النتائج المستهدفة

- فهم الحروف وأصواتها ودمجها والقراءة والتهجئة والكتابة عبر لوحة المفاتيح.
- بناء مفردات نشطة وعبارات واقعية.
- فهم القواعد وتطبيقها في السياق.
- تطوير القراءة والكتابة والاستماع والتحدث تدريجيًا.
- فهم المحتوى اليومي والأكاديمي والمهني.
- الوصول إلى توصيفات CEFR من Pre-A1 إلى C2.

## 5. مبادئ المنتج

1. المجانية الكاملة للمتعلمين دون إعلانات أو اشتراكات أو ميزات مدفوعة.
2. عدم الاعتماد على فترات تجريبية لخدمات تنتهي مجانيتها.
3. Offline-first بعد أول تسجيل دخول وتنزيل المنهج.
4. منهج أصلي ومراجع، مع مصادر خارجية مرخصة.
5. تقييم إتقان حقيقي لا يعتمد على الحفظ السريع.
6. واجهة بسيطة لا تكدس المعلومات على المتعلم.
7. خصوصية وتقليل بيانات غير ضرورية، مع إحصائيات تعليمية تفصيلية للإدارة ضمن صلاحيات.
8. لا منافسات أو قوائم ترتيب أو شهادات غير معتمدة.
9. لا IPA ولا تقييم صوتي للمتعلم.
10. بنية قابلة للنقل بين مزودي الاستضافة والتخزين.

## 6. المنصات

- Web: React + TypeScript + PWA.
- Android: Capacitor.
- Windows: Tauri.
- Backend: Hono + TypeScript على Cloudflare Workers.
- Database: PostgreSQL على Neon.
- Local data: IndexedDB للويب وSQLite للتطبيقات.
- Storage: طبقة مزود مستقلة؛ Neon Object Storage وR2 مرشحان، ويُختار مزود الإنتاج بعد إثبات المجانية دون بطاقة أو فترة تجريبية أو فوترة غير مقصودة.

## 7. النطاق غير المستهدف

- لا شهادات أكاديمية أو مهنية يصدرها المشروع من تلقاء نفسه.
- لا تقييم آلي لصوت المتعلم.
- لا رموز IPA.
- لا منافسات اجتماعية أو لوحات ترتيب.
- لا إعلانات أو اشتراكات أو محتوى مدفوع.
- لا نشر تلقائي لمحتوى تعليمي مولد آليًا.
- لا وعد بتشغيل استضافة مجانية غير محدودة إلى الأبد.

## 8. الحوكمة

- مدير رئيسي.
- محررو محتوى.
- مراجعون.
- مسؤولو نشر.
- أدوار وصلاحيات منفصلة.
- سجل تدقيق وإصدارات للمحتوى.
- مساهمات المجتمع عبر Pull Requests ومراجعة إلزامية.

## 9. تعريف النجاح

يُقاس النجاح بجودة المنهج ودقة المحتوى واستقرار العمل دون اتصال وإمكانية التوسع وإمكانية إثبات الإتقان، وليس بعدد الميزات أو سرعة إصدارها فقط.

## 10. قيود وقرارات مفتوحة

تُدار القرارات غير المحسومة في `docs/DECISIONS.md`. لا يُعتمد مزود أو محرك صوت أو خدمة بريد لمجرد وجود خطة مجانية معلنة؛ يجب التحقق من شروط التسجيل والبطاقة والفوترة وحدود الاستخدام وتوافق الترخيص.
