# H2 — بناء حاوية APK بملف placeholder

**الحالة:** لم يبدأ التنفيذ وقت كتابة معايير القبول.  
**تاريخ التسجيل:** 2026-11-01.  
**موعد الانتهاء:** 2026-11-08، 23:59 بتوقيت Africa/Algiers. لا تمديد دون قرار موثق في DECISIONS ومصفوفة التتبع.  
**النطاق:** Android عبر Capacitor فقط. هذا الشاهد لا يثبت Windows/Tauri.

## السؤال القابل للتكذيب

هل يمكن لسلسلة Capacitor/Android إنتاج APK قابل للتثبيت والتشغيل، يحتوي ملف placeholder كبيرًا داخل الأصول التي تُشحن فعلًا، دون أن يخرق ذلك حدود البناء أو التغليف أو التثبيت؟

## معيار الحجم المسجل قبل الكود

يُستخدم ملف اختبار عشوائي عالي الإنتروبيا بحجم **128 MiB** لتجنب أن يضغطه ZIP بسهولة ويعطي انطباعًا مضللًا عن حجم payload. هذا **حد اختبار هندسي مؤقت، وليس تقديرًا مثبتًا لحجم المنهج النهائي**؛ لم تُحصر بعد أحجام نصوص المنهج والصوت والصور. أي ادعاء عن ملاءمة المنهج الفعلي يحتاج inventory حقيقيًا لاحقًا.

## معايير القبول المسجلة قبل الكود

1. **H2 ناجح** فقط إذا:
   - أنتجت سلسلة البناء الفعلية ملف APK debug قابلًا للتثبيت.
   - احتوى APK على ملف placeholder كاملًا بطول 134,217,728 بايت (128 MiB).
   - ثُبّت APK وشُغّل على Android Emulator واحد على الأقل، مع نتيجة تشغيل ناجحة.
   - سُجل حجم APK النهائي بالبايت وMiB، وزمن البناء، وزمن تثبيت/إطلاق التطبيق، وإصدار Capacitor/Gradle/AGP/JDK/SDK.
   - سُجل نوع التوقيع: اختبار debug signing فقط؛ هذا لا يثبت جاهزية مفتاح إصدار الإنتاج أو توقيع Windows.
2. **H2 يفشل** إذا فشل أي شرط من شروط البناء/الاحتواء/التثبيت/التشغيل. يُحفظ log الفشل، ولا يُخفى خلف إعادة محاولة غير موثقة.
3. **تعذّر الإثبات** نتيجة مستقلة إذا لم تتوفر بيئة/صلاحية أو جهاز/محاكي أو إذا انتهى الموعد؛ لا يُمدد الموعد ضمنيًا.
4. لا يُغيّر حجم placeholder أو منصة الاختبار بعد ظهور النتائج دون تسجيل: «تعديل معيار بعد ملاحظة …» مع السبب والنتيجة التي لن تعود قابلة للمقارنة.

## ما لا يثبته هذا الشاهد

- لا يثبت H1: لا يجري اختبار manifest أو checksum أو signature verification أو رفض ملف معدل.
- لا يثبت H3: لا يقرأ التطبيق payload من داخل APK وقت التشغيل ولا يحسب checksum له.
- لا يثبت H4: نجاح البناء والاحتواء لا يعني نجاح قراءة الحزمة والتحقق منها داخل التطبيق كما ستُشحن.
- لا يثبت حجم المنهج النهائي أو ملاءمته للأجهزة أو تحديثه أو تراجعه.
- لا يثبت Tauri/Windows أو Authenticode أو توزيع EXE.

## سقف النطاق — لا دمج تلقائي

يسمح لهذا الشاهد فقط بواجهة Capacitor فارغة ورسالة تشغيل وملف placeholder ثابت الحجم وأوامر قياس. لا درس ولا حسابات ولا قاعدة بيانات ولا مزامنة ولا مدير محتوى ولا محرك منهج. مجلد الشاهد وworkflow خاصته لا يُنقلان إلى تطبيق الإنتاج. دمج أي جزء في المنتج قرار منفصل ضمن ROADMAP وPR مستقل.
